# 국어 내신 변형 문제 프롬프트 템플릿

독서·문학 지문으로 **오류 없는 내신 변형 문제**를 만들기 위한 프롬프트 모음입니다.
Claude 앱(또는 다른 최상위 AI)에 복사해서 쓰면 됩니다.

## 사용 순서

| 단계 | 프롬프트 | 어디서 |
|---|---|---|
| 1 | **① 출제 프롬프트**에 자료를 채워 넣고 문제 만들기 | 새 대화 A |
| 2 | **② 검수 프롬프트**에 지문·필기·1단계 결과를 넣고 검사 | **새 대화 B** (반드시 따로) |
| 3 | 검수에서 `수정`·`폐기`가 나온 문항은 **③ 수정 프롬프트**로 고치기 | 대화 A |
| 4 | 최종본을 직접 훑어보기 (근거 문장 번호만 확인하면 됨) | 본인 |

> **왜 검수는 새 대화에서?** 같은 대화에서 검수하면 AI가 자기가 만든 문제를 두둔하는 경향이 있어요.
> 새 대화에서는 처음 보는 문제처럼 풀어 보기 때문에 오류를 훨씬 잘 잡아요.

## 자료 넣는 요령

- **지문 원문**: 반드시 교과서·부교재에서 그대로 복사. AI에게 지문을 "기억해서" 쓰게 하지 마세요.
- **필기**: 사진을 그대로 올려도 되지만, 중요한 해석은 글로 옮겨 적으면 더 정확해요.
- **예시 문제**: 학교 기출이나 학원 변형 문제 2~3개면 충분해요. 스타일 참고용입니다.
- 없는 자료 칸은 `없음`이라고 적으세요. 단, **문학은 필기가 없으면 해석 오류 위험이 커요.**
- 학원 자료는 개인 공부용으로만 쓰고 외부에 공유하지 마세요.

## ① 출제 프롬프트

아래 전체를 복사한 뒤 `[ ]` 칸만 채워서 보내세요.

````text
너는 고등학교 국어 내신 시험 출제 위원이다. 아래 자료만을 근거로 변형 문제를 만든다.

# 자료

## 1. 지문 종류
[독서 / 문학(현대시·고전시가·현대소설·고전소설·수필·극) 중 하나]

## 2. 지문 원문
"""
[지문을 그대로 붙여 넣기]
"""

## 3. 선생님 필기 / 수업 해석
"""
[필기 내용 붙여 넣기. 없으면 '없음']
"""

## 4. 예시 변형 문제 (스타일 참고용)
"""
[학교 기출이나 학원 문제 2~3개. 없으면 '없음']
"""

## 5. 출제 조건
- 문항 수: [예: 객관식 6개 + 서술형 2개]
- 난이도: [예: 중 3개, 상 3개]
- 꼭 넣을 유형: [예: <보기> 적용 1개 이상. 없으면 '자유']

# 출제 규칙 (반드시 지킬 것)

1. 먼저 지문의 문장마다 번호를 붙여 [S1], [S2] ... 형태로 다시 출력한다. (시는 행 단위로 [L1], [L2] ...)
2. 모든 정답과 오답 판단의 근거는 **지문 원문과 필기 안에서만** 찾는다. 배경지식·작가 정보·외부 해설을 근거로 쓰지 않는다.
3. 필기와 너의 해석이 다르면 **필기를 따른다.**
4. 필기에 없는 해석이 필요한 문항(특히 문학의 주제·태도·의미)은 문항 끝에 `[필기 확인 필요]`를 붙인다.
5. 객관식은 5지선다이며 **정답은 반드시 하나**다. 두 개 이상이 맞을 여지가 있으면 그 문항은 버리고 다시 만든다.
6. 오답 선지는 확실히 틀려야 하며, 아래 방식 중 하나로 만든다:
   - 독서: 사실 왜곡, 인과 뒤집기, 범위 과장·축소, 주체·대상 바꾸기, 개념 혼동, 지문에 없는 내용
   - 문학: 표현법 오인, 화자·인물 태도 오독, 시어·소재 의미 오해, 시점·서술 방식 오인, 필기와 다른 해석
7. 오답이 너무 티 나지 않게, 지문의 표현을 일부 그대로 가져와 헷갈리게 만든다. 단, 억지로 말장난을 하지 않는다.
8. 예시 변형 문제가 있으면 그 발문 방식, 선지 길이, 난이도를 최대한 따라 한다.
9. 정답 번호가 한쪽에 몰리지 않게 섞는다.

# 참고 유형

- 독서: 내용 일치/불일치, 세부 정보 추론, 핵심 개념 비교, 문단 구조, <보기> 사례 적용, 문맥적 의미, 서술형 요약
- 문학: 표현상 특징, 시어·소재의 기능, 화자·인물의 태도와 정서, <보기> 관점 감상, 작품 간 비교, 서술형 해석

마지막에 `[필기 확인 필요]`가 붙은 문항 번호를 모아서 목록으로 보여 준다.
````

## ② 검수 프롬프트

**반드시 새 대화에서** 사용하세요. ① 결과의 "문제"와 "정답과 근거"를 모두 붙여 넣습니다.

````text
너는 고등학교 국어 내신 시험의 검토 위원이다. 다른 출제자가 만든 변형 문제에 오류가 있는지 엄격하게 검사한다. 출제자를 배려하지 말고, 조금이라도 논란이 될 여지가 있으면 지적한다.

# 지문 원문
"""
[지문 붙여 넣기]
"""

# 선생님 필기 / 수업 해석
"""
[필기 붙여 넣기. 없으면 '없음']
"""

# 검수할 문제 (정답과 근거 포함)
"""
[① 출제 결과 전체 붙여 넣기]
"""

# 검수 방법

각 객관식 문항마다 아래 순서를 지킨다.

1. **먼저 출제자의 정답과 근거를 보지 말고** 지문과 필기만 보고 직접 푼다. 너의 답을 적는다.
2. 출제자의 정답과 비교한다. 다르면 누가 맞는지 근거 문장으로 따진다.
3. 아래 항목을 하나씩 확인한다.
   - (가) 정답 유일성: 정답 외에 맞다고 볼 여지가 있는 선지가 있는가?
   - (나) 오답 확실성: 오답 선지 중 "해석에 따라 맞을 수도 있는" 것이 있는가?
   - (다) 근거 정확성: 적힌 근거 문장 번호가 실제로 그 판단을 뒷받침하는가?
   - (라) 외부 지식: 지문·필기 밖의 지식이 있어야 풀 수 있는가?
   - (마) 필기 일치: 필기의 해석과 어긋나는 내용이 있는가?
   - (바) 형식: 발문과 선지가 맞물리는가? ("적절하지 않은 것" 발문인데 정답이 적절한 것 등) 맞춤법·용어 오류는?
   - (사) 난이도: 표시된 난이도와 실제 체감 난이도가 맞는가?

서술형은 모범 답안이 지문·필기와 맞는지, 채점 기준이 명확한지 확인한다.

# 출력 형식

## 문항별 판정
**문항 N — 판정: 통과 / 수정 / 폐기**
- 내 풀이 답: ○ (출제자 답: ○)
- 문제점: (없으면 '없음') 어느 항목(가~사)에 걸리는지와 이유
- 수정 제안: 어떤 선지를 어떻게 바꾸면 되는지 구체적으로

## 요약
- 통과: 문항 번호
- 수정: 문항 번호
- 폐기: 문항 번호
- 사람이 직접 확인해야 할 부분: (필기와 대조가 필요한 해석 등)
````

## 마지막 본인 확인 체크리스트

- [ ] `[필기 확인 필요]` 문항을 필기와 직접 대조했다
- [ ] 정답 선지의 근거 문장 번호를 지문에서 찾아 읽어 봤다
- [ ] 헷갈렸던 오답 선지는 왜 틀렸는지 설명할 수 있다

마지막 항목이 되면 그 문항은 이미 **공부가 끝난 것**입니다.
