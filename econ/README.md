# 경제 튜터

Claude에게 묻는 한국어 경제학 튜터 챗봇.

- 앱: https://claude.ai/artifact/SCy6xivPdPR8Vi6E4gj9Bs (본인만 열 수 있음)
- artifact의 `sample` 기능으로 보는 사람의 Claude 계정에 질문한다(처음 한 번 허용을 묻는다)

## 모드

- 개념 설명: 직관 → 정의 → 원리 → 예시 → 헷갈리는 점 → 요약
- 문제 풀이: 조건 정리 후 단계별 계산, 정답 굵게
- 시사 해설: 붙여 넣은 기사나 이슈를 인과 사슬로 해설 (검색은 하지 않음)
- 퀴즈: 한 문제씩 내고 채점·해설 후 다음 문제

수준(고등학교 / 경제원론 / 중급)과 답변 깊이(빠르게 / 보통 / 깊게 생각)를 고를 수 있다.
대화는 모드별로 이 브라우저의 localStorage에만 저장되고, 최근 20턴만 Claude에 보낸다.

`index.html`을 고친 뒤에는 같은 주소로 다시 발행한다.
