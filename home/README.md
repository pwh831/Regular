복습 플래너·영단어 시험·오답 코치를 한 화면에 모은 시작 화면. 오늘 할 일(과목 구분 없이 한 목록), 8과목 D-day와 최근 7일 진도, 이번 주 완료 현황, 공부 앱 바로가기.

- 앱: https://claude.ai/artifact/HVXCKJ64TP8oUNamPwj6DC (본인만 열 수 있음)

## 구조

앱끼리는 서로의 db를 읽을 수 없어서, 루틴 "공부 홈 요약 갱신"(06:25 · 16:25 · 20:25 KST)이
세 앱의 db를 내려받아 `aggregate.py`로 요약을 만들고 홈의 `snapshot/main` 문서에 쓴다. 홈은 그 문서만 읽는다.

- 새로고침 버튼: `mcp` 기능으로 claude.ai 커넥터 "Claude Code Remote"의 `fire_trigger`를 불러 루틴을 지금 한 번 돌린다(1분쯤). 커넥터를 못 쓰면 버튼이 숨는다.
- `aggregate.py`는 루틴 프롬프트 안에 그대로 들어 있다. 고치면 루틴 프롬프트도 같이 바꿔야 한다.
- 홈에서 체크하지 않는다. 항목을 누르면 원래 앱으로 가서 거기서 완료한다(두 곳 기록이 어긋나지 않게).
