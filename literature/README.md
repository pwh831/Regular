# 문학과 영상 지필고사

「문학과 영상」 1단원 「문학과 영상 만나기」(교과서 10~43쪽), 이성부 「봄」, 시나리오 용어 프린트, 수업 필기(빨간 펜)로 지필고사 모의고사를 만들고 채점해 주는 앱. 출제·채점·질문은 Claude가 한다.

- 앱: https://claude.ai/artifact/Cy11ZFb1hWvjp1YxnW84JX (본인만 열 수 있음)
- artifact의 `sample` 기능으로 보는 사람의 Claude 계정에 요청한다(처음 한 번 허용을 묻는다)
- 시험 정보(필기): 객관식 70점 · 서답형 30점, 옷소매 쪽 "객관 21, 서답 8", 「문학과 영상이 세상을 그리는 방법」 지문 전체가 범위

## 파일

- `index.html`: 앱
- `materials.js`: 범위 본문을 옮겨 적은 자료. `【필기: …】`는 빨간 펜 필기, **굵은 글씨**는 교과서 빨간 네모 부분. 출제·채점·질문 프롬프트에 그대로 들어가고 암기 카드(`cards`)도 여기 있다

## 탭

- 모의고사: 범위 8개 중 선택, 문항 수(객관식 0~30, 서답형 0~15 직접 입력, 빠른 선택: 실전 21+8 / 절반 10+4 / 짧게 6+2 / 서답형만 0+5), 난이도 → 시험지. 객관식은 바로 채점, 서답형은 채점 기준으로 부분 점수 시험지 화면의 "PDF로 받기"로 문제지+정답·해설을 A4 PDF로 저장(`downloads` 기능)
- 암기: 용어 카드(뒤집기, 외웠어요/다시 볼래요, 외운 카드는 이 브라우저에 저장), 범위 본문·필기 보기
- 서답형: 문제와 내 답안(사진 가능) → 예상 점수, 항목별 근거, 고쳐 쓴 모범 답안
- 오답: 틀린 문항 모음, "비슷한 문제 풀기", "이제 알아요"
- 질문: 범위 안에서 개념·장면 질문 (대화는 이 브라우저 localStorage에만)

## 데이터 (artifact db)

- `exams/<id>`: `{title, createdAt, secs, scope, status: draft|done, questions, answers, graded, mastered, submittedAt}` (문항 형식은 경제 앱과 같다)

`index.html`이나 `materials.js`를 고친 뒤에는 같은 주소로 다시 발행한다(`materials.js`는 `files`로 함께 올린다).
