# 독서 내신 공부 원리 (검증 정리)

사용자가 준 자료 「완벽한 기출분석 백서」 1~3권의 주장을 학습과학 연구와 대조해 정리했다.
앱의 공부 기능과 프롬프트는 **근거 강함** 항목을 뼈대로 삼고, 과장된 주장은 쓰지 않는다.

## 1. 근거 등급

### 근거 강함 (여러 실험과 메타분석으로 반복 확인)

| 원리 | 자료의 표현 | 연구 근거 | 독서 내신에 쓰는 법 |
|---|---|---|---|
| **인출 연습** (시험 효과) | 아웃풋 공부, 백지 인출, 플래시카드 | Roediger & Karpicke(2006): 다시 읽기보다 꺼내 보기를 한 쪽이 1주 뒤 훨씬 많이 기억. Dunlosky 외(2013) 10가지 공부법 평가에서 "효용 높음" | 지문을 덮고 문단 구조·핵심 문장을 적어 본 뒤 대조. 지문 문장을 OX로 꺼내 보기 |
| **분산 학습** | 회독 시스템 | Cepeda 외(2006) 메타분석. 같은 시간이라도 날을 나눠 공부하면 오래 감. 시험까지 남은 기간의 대략 10~20% 간격이 효과적(Cepeda 외 2008) | 같은 지문을 하루에 몰아 보지 말고 1·3·7일 뒤 다시 인출. 복습 플래너와 연결 |
| **연속 재학습** (successive relearning) | 스피드패스 카드 | Rawson & Dunlosky(2011~): 한 번 공부할 때 맞힐 때까지 인출하고, 그걸 며칠 간격으로 반복하면 오래 가고 다음 회차 시간이 빠르게 줄어듦 | OX·카드를 그날 연속 2~3번 맞힐 때까지 돌리고, 다음 복습일에 다시. "회독할수록 분량이 줄어드는" 구조의 실제 근거 |
| **유창성의 착각** | 유창성의 착각 | Bjork의 "바람직한 어려움", 학습 판단 연구(Koriat 등). 다시 읽으면 익숙해서 안다고 착각함 | "읽어 보니 아는 것 같다"를 판단 기준으로 쓰지 않는다. 판단은 인출 결과로만 |
| **처리 깊이** | 심층 처리 | Craik & Lockhart(1972) 이후 다수. 뜻과 관계를 따지며 읽은 내용이 더 오래 남음 | 문장 간 관계(원인-결과, 비교, 전제-결론)를 내 말로 바꿔 보기 |
| **생성 효과** | 나만의 언어로 재구성 | Slamecka & Graf(1978) 이후 반복 확인. 스스로 만들어 낸 정보가 읽기만 한 정보보다 잘 기억됨 | 2~3문장 가리고 재구성, 지문 요약을 먼저 써 보고 해설과 대조 |
| **수면과 기억 공고화** | 수면 7시간 자산화 | 수면 중 해마-신피질 공고화. 수면 박탈 뒤에는 새 기억 형성이 크게 떨어짐(Yoo 외 2007) | 시험 전날 밤샘은 손해. 청소년 권장 수면은 8~10시간(미국수면의학회). 7시간은 최소치로 보는 게 맞음 |

### 근거 중간 (효과는 있지만 조건이 붙음)

| 원리 | 연구 근거와 조건 | 쓰는 법 |
|---|---|---|
| **교차 학습** (인터리빙) | Rohrer & Taylor(2007) 등. 비슷해서 헷갈리는 유형을 구별해야 할 때 특히 효과. 처음 배울 때는 덜 효과적 | 시험 직전 단계에서 여러 지문의 변형 문제를 섞어 풀기. 처음 익힐 땐 한 지문씩 |
| **정교화 질문 · 자기 설명** | Dunlosky 외(2013) "효용 중간". "왜?"를 묻고 스스로 설명하면 이해가 깊어짐. 배경지식이 있을수록 효과 큼 | 핵심 문장마다 "왜 그런가?"를 지문 근거로 답하기. 파인만 기법의 근거가 이쪽 |
| **사전 시험 효과** | 배우기 전에 먼저 풀어 보면(틀려도) 그다음 학습이 나아짐(Richland 외 2009, Kornell 외) | 수업 전 지문을 읽고 OX 몇 개를 먼저 풀어 보기 |
| **확신도 표시** | 메타인지 보정. 맞혔어도 확신 없는 답은 모르는 것으로 처리해야 실수가 줄어듦 | 자료의 "3색 근거 추적"과 같은 원리. 앱에서 "확신/애매/모름" 표시 |
| **가사 있는 음악** | 가사가 독해를 방해한다는 실험이 여럿(Perham & Currie 2014 등). 연주곡·소음은 개인차 | 독서 공부 중에는 가사 있는 음악 끄기 |
| **방해 요소 차단** | 과제 전환에는 비용이 있음. 휴대폰이 곁에 있기만 해도 떨어진다는 연구(Ward 외 2017)는 재현 결과가 엇갈림 | 알림 끄고 다른 방에 두기는 손해 볼 게 없는 선택 |
| **짧은 운동** | 중간 강도 운동 직후 인지 수행이 조금 좋아진다는 메타분석(Chang 외 2012). 효과는 작음 | 졸릴 때 스쿼트·걷기는 괜찮은 각성법 |

### 근거 약함 또는 과장 (앱에서 쓰지 않음)

| 자료의 주장 | 실제 |
|---|---|
| 게이츠 실험에서 아웃풋 70% 그룹이 기억 정착률 **2.5배** | Gates(1917)는 시간의 상당 부분(최대 80%)을 암송에 쓴 쪽이 낫다고 보고했지만 "2.5배"라는 수치의 출처는 확인되지 않는다. 방향은 맞고 숫자는 근거 없음 |
| 인터리빙으로 실전 응용력 **43%** 상승 | 연구마다 효과 크기가 다르고 이 수치의 출처가 없다 |
| 스쿼트 20회면 BDNF가 분비되어 **10초 만에** 집중력 회복 | 운동이 BDNF를 늘리는 건 맞지만 10초 만의 집중력 회복은 근거 없음. 각성 효과는 있음 |
| 실패의 90%는 **도파민 고갈**, 숏폼이 도파민 수용체를 **마비** | 과장된 비유. 숏폼이 주의 습관에 나쁠 수 있다는 정도가 현재 근거 수준 |
| 타이핑이 **최속** 인출법 | 손글씨와 타자 비교 연구(Mueller & Oppenheimer 2014)는 재현에서 차이가 작거나 없었다. 인출 자체가 핵심이고 도구는 편한 걸 쓰면 됨 |
| 쉬는 시간 **9분 59초**, 2분 프리라이팅의 **2분** | 정해진 수치에 근거는 없다. 짧게 쉬고 다시 시작하는 원리 정도 |
| 황제 기상법으로 기상 성공률 **급증** | 누워서 인출해 보는 건 좋은 인출 연습이지만 기상률 주장은 근거 없음 |
| 하루 끝에 다음 단원 1~2쪽 더 읽기 (자이가르닉 효과) | 자이가르닉 효과는 재현이 약하다. 다음 날 시작이 쉬워진다는 실용적 효과 정도 |
| 형광펜 2색 단권화 | 밑줄·형광펜 자체는 Dunlosky 외(2013)에서 "효용 낮음". 정리용으로는 괜찮지만 공부 시간으로 치면 안 됨 |

## 2. 독서 내신의 특징

수능 독서와 다르다. **지문이 미리 정해져 있고**, 출제자는 우리 학교 선생님이다.

- 시험장에서 처음 읽는 글이 아니라 **이미 아는 글**을 다시 만난다. 그래서 "지문 내용을 장기 기억에 넣어 두기"가 점수의 큰 몫을 차지한다. 인출 연습과 분산 학습이 그대로 들어맞는 영역이다.
- 선지는 **지문 문장을 비틀어** 만든다 (인과 뒤집기, 범위 과장, 주체 바꾸기 등). 그래서 문장 하나하나의 정확한 내용, 특히 수식어·조건·예외를 기억해야 한다.
- 해석이 갈리는 부분은 **선생님 수업 내용이 정답**이다. 필기가 1순위 자료다.
- 100점을 막는 건 대개 모르는 문제보다 **애매하게 알던 문제**다. 확신도 표시와 "맞힐 때까지 재인출"이 이걸 없앤다.

## 3. 최소 시간으로 100점을 노리는 지문별 흐름

시간이 적게 드는 이유: 다시 읽기(효용 낮음)를 빼고, 이미 맞히는 것은 건너뛰고, 틀리는 것에만 시간을 쓴다.

| 시점 | 할 일 | 원리 | 시간(지문 1개) |
|---|---|---|---|
| 수업 전 | 지문을 한 번 읽고 OX 5개를 먼저 풀어 보기 | 사전 시험 효과 | 5분 |
| 수업 당일 | **가림 읽기**: 2~3문장씩 읽고 가린 뒤 관계를 내 말로 한 줄 적기 | 처리 깊이, 생성 효과 | 15분 |
|  | **백지 인출**: 지문을 덮고 문단별 핵심과 문장 관계를 적은 뒤 지문·필기와 대조. 빠진 것만 표시 | 인출 연습 | 10분 |
| 1·3·7일 뒤 | **OX 연속 재학습**: 지문 문장 기반 OX를 1초 안에 판단. 틀리거나 애매하면 다시 넣어 연속 2번 맞힐 때까지 | 연속 재학습, 분산 | 5~10분, 회차마다 줄어듦 |
|  | 백지 인출 다시 (빠진 것만 확인) | 인출 연습 | 5분 |
| 시험 1~2주 전 | **변형 문제**: 여러 지문을 섞어서. 틀리면 원인 분류(지문 내용 / 선지 독해 / 해석 차이 / 시간) | 교차 학습, 메타인지 | 지문당 15분 |
|  | 원인이 "지문 내용"이면 그 문장을 OX에 추가 | 연속 재학습 | |
| 시험 전날 | 지금까지 틀렸거나 애매했던 OX만 | 분산의 마지막 회차 | 10분 |
| 시험 전날 밤 | 충분히 자기 | 수면 공고화 | |
